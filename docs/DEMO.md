# AgentFence 오프라인 시연

`python -m pytest -q -s tests/test_demo.py`로 실행합니다. 임시 작업 폴더에 만든 샘플 파일만 사용합니다.

| 측정 지표 | 시나리오 | 로컬 결과 |
|---|---|---|
| 정상 요청 허용 및 실행 성공 | 읽기, 목록, 생성, 수정, 삭제 | 5/5 (100%) |
| 정책 미허용 요청 차단 | 읽기, 수정, 삭제, 생성 | 4/4 (100%) |

정책에 없는 수정과 삭제 후 샘플의 내용이 유지되고, 허용되지 않은 생성으로 파일이 생기지 않는 것을 검사합니다. 이 수치는 준비한 9개 요청에 대한 결과입니다.

실제 Gemini 시연은 `GEMINI_API_KEY`와 사용할 `GEMINI_MODEL`을 설정한 후 `python main.py --audit`로 시작합니다. 첫 요청은 `public.txt 내용을 읽어줘`로 확인합니다. 이 단계에는 실제 API 호출이 필요합니다.
