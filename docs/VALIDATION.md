# 검증 기록

2026-10-30, Windows / Python 3.14.3.

실행 명령:

```text
python -m unittest discover -s tests -v
```

28개 테스트 중 25개 통과, 3개 건너뜀, 실패 0개.
건너뛴 항목은 POSIX 전용 디스크립터/FIFO 테스트와 Windows 권한이 필요한 파일 심볼릭 링크 테스트입니다.
Windows 디렉터리 junction, 실제 하드링크, 디렉터리 이름 교체는 실제 파일시스템에서 검증했습니다.
GitHub Actions는 Ubuntu/Windows × Python 3.11/3.14에서 같은 테스트를 수행하도록 구성했습니다.
CI 결과는 저장소 Actions에서 별도로 확인합니다.

| 범위 | 확인 내용 |
|---|---|
| 기본 Tool | 읽기/전체 교체/목록/배타 생성/삭제 |
| 공통 계약 | 응답 키, 요청 버전/ID/자료형, 추가 인자, JSON 중복 키 |
| 기본 차단 | 5개 작업의 비인가 요청에 실행기 호출이 없고 파일도 그대로 유지 |
| 경로 | `..`, 절대/UNC/드라이브 상대 경로, 역슬래시, ADS, 장치 이름, 8.3 별칭 |
| 정책 | 누락/손상/중복/와일드카드/미등록 Tool/보호 경로/잘못된 키 모두 차단 |
| 정책 분리 | workspace 내부 정책 설정 거부 |
| 이름 노출 | 목록에서 비인가 파일/생성 전용 파일/하드링크 제외 |
| 파일 조건 | 기존 파일 생성 거부, 없는 파일 수정 거부, 디렉터리 파일 작업 거부 |
| 내용 | UTF-8, 읽기/쓰기 바이트 한도, 잘못된 UTF-8 오류 |
| 링크 | 외부 하드링크 읽기/쓰기/삭제 차단, junction 외부 우회 차단 |
| 경쟁 상황 | 정책 검사 후 열기 직전 하드링크 교체 시 유출/변경 없음 |
| 디렉터리 교체 | 핸들을 연 뒤 디렉터리를 옮기고 junction으로 바꿔도 외부 파일을 읽지 않음 |
| 승인 경계 | 원시 경로/approved 플래그로 내부 Tool 직접 호출 거부 |
| 모델 연동 | 모든 Tool Call이 게이트웨이를 경유하고 BLOCK도 모델에 반환 |
| Gemini 계약 | 병렬 제안 처리, 함수 ID/원본 thought signature 보존, 키 payload 제외 |
| 제한/로그 | 최대 호출 수, 감사 로그에 경로/내용/예외 제외 |

실제 Gemini API는 키를 사용하거나 호출하지 않았습니다. 가짜 REST 전송으로 연동 계약을 검증했습니다.
